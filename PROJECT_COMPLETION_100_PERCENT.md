### Animation System (Established Patterns)

```
FADE ANIMATIONS
├── fade-down: Page headers (600ms)
├── fade-up: Content cards, list items (700ms)
├── fade-right: Titles and subtitles (100-150ms delay)
├── fade-left: Sidebar content

ZOOM & SCALE
├── zoom-in: CTA buttons, hero elements (300-400ms)
├── scale-up: Card hovers (200-300ms)

SLIDE ANIMATIONS
├── slide-in-right: Success/error messages (400ms)
├── slide-in-left: Sidebar animations

STAGGER PATTERNS
├── Table rows: 50ms delay between each
├── Card grids: 100-150ms delay increments
├── Feature lists: 50-100ms progression

TIMING CONFIGURATION
├── Default Duration: 600-700ms
├── Easing: cubic-bezier(0.4, 0, 0.2, 1)
├── Offset: 100px (starts animation when element 100px in viewport)
├── Once: false (animations repeat on scroll)
```
